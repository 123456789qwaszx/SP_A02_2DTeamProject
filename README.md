# 🌌 Fallen Angel

> 지옥에서 시작된 복수의 여정, 바벨탑을 오르며 천상계에 맞선 타락천사의 이야기.

---

## 🎮 기본 조작법

| 동작         | 키보드 / 마우스 |
|--------------|-----------------|
| 이동         | `W`, `A`, `S`, `D` |
| 기본 공격    | 마우스 `좌클릭` |
| 인벤토리 열기 | `I` |
| 닫기         | `ESC` |

---

## 🧪 치트키 (디버깅용)

| 키 | 효과                           |
|----|--------------------------------|
| `Q` | 플레이어 속도 2배 증가         |
| `F` | 현재 스테이지 즉시 클리어     |
| `Z` | 전체 스테이지 클리어 처리     |
| `X` | 스테이지 시간 1분 추가        |
| `C` | 무적 모드 토글                |
| `V` | 보스 즉시 처치                 |

## 🕯️ 게임 컨셉 & 스토리

> "그 날, 신은 나를 버렸다.  
> 나는 이제, 신이 아니다."

‘**유일신**’의 명령 아래에 있던 **7대 천사**.  
하지만 유일신은 과거 자신의 실수를 감추기 위해, 죄 없는 천사인 ‘**주인공**’에게 죄를 뒤집어씌우고 **지옥**으로 추방한다.

타락한 날개, 그리고 복수를 향한 불타는 의지.  
주인공은 **바벨탑**을 올라 유일신에게 다가가려 한다.

탑을 오르는 여정 속에서, 주인공은 다양한 **천사 (보스)ㅂ**들을 마주친다.  

주인공은 결국 유일신에게 도달해 어떤 결말을 맞이하게 될 것인지...
